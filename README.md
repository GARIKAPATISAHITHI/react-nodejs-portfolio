# React / Node.js Portfolio

A collection of sample projects demonstrating modern frontend and full-stack development using React, Next.js, TypeScript, Node.js and related technologies.

## Technologies

- React
- Next.js
- TypeScript
- Node.js
- Express.js
- REST APIs
- PostgreSQL
- MongoDB
- Docker

## Areas Demonstrated

- Reusable React components
- State management
- REST API integration
- Responsive UI development
- Backend API development
- Database integration
- Testing
- Performance optimization
